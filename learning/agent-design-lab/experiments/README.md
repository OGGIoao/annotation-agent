# 实验记录

每一站单独建立目录，并至少包含：

```text
Lx-name/
├── README.md       # 本站目标、命令和验收
├── code/           # 本站实验代码
├── tests/          # 本站测试
└── RETRO.md       # 运行结果和复盘
```

## 当前实验顺序

- `L0-environment/`：环境自检和最小函数；
- `L1-contracts/`：数据契约和确定性校验；
- `L2-workflow/`：状态、节点和条件路由；
- `L3-structured-output/`：FakeModel 与结构化候选；
- `L4-visual-evidence/`：页面块、坐标和预览；
- `L5-tool-execution/`：ActionPlan、FakeExecutor、Receipt；
- `L6-human-review/`：暂停、人工决定和恢复；
- `L7-evaluation/`：固定样本、指标和迁移报告。

实验将随每站开始逐步创建，不提前堆空目录或伪实现。
